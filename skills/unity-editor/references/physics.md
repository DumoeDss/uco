# Physics queries, colliders, rigidbodies, and simulation

Inspect objects, components, transforms, layers, and physics settings. Keep observation-only queries separate from serialized mutations. For nested shapes/filters, query one exact schema. Validate changes with a deterministic query or focused PlayMode test.

Do not infer collider bounds from mesh appearance. Keep world/local coordinates, trigger policy, layer masks, 2D versus 3D physics, and fixed-step timing explicit. Restore temporary simulation/diagnostic settings.
