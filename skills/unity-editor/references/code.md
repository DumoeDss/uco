# C# scripts, packages, docs, types, and reflection

Prefer `rg`, normal filesystem reads, and structured patches for local C# source. Use uco script tools for remote access, guarded edits, or Unity-owned representations. After source/package changes, wait for compilation/domain reload, inspect new console errors, and run the smallest relevant test.

Prefer documented typed tools over reflection or arbitrary execution. Inspect a reflected method signature first and verify effects immediately. Do not repeat a package mutation merely because the bridge disappears during reload.
