# Cameras, graphics, UI, textures, screenshots, and VFX

Inspect the render pipeline, scene, camera, and target assets first. Resolve references rather than guessing GUIDs. Make one coherent change, allow imports/shader compilation to finish, inspect console/graphics diagnostics, and view the produced image locally.

Use Game view for player-facing composition and Scene view for authoring state. Batch/no-graphics runs do not provide a normal Game view. For UI, validate hierarchy, target resolutions, assets, interaction states, and contrast.
